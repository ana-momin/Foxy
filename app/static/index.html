Foxy GitHub

Finds YC founders before YC announces them.

A Slack bot that watches five sources and tells you which new companies the market hasn't seen yet.

Runs free Every 8 hours Python or Docker

Why

The directory is a lagging indicator.

24 Listed by YC
100s Actually in the batch

Everyone scraping YC's directory finds the same companies on the same day. The founders not yet listed are already posting about it.

Foxy reads those posts first, then checks the directory. If YC hasn't published them, it says so — that's the window where an email still lands first.

Setup

Five minutes, one token.

01

Create the Slack app

At api.slack.com/apps choose From an app manifest and paste in slack-app-manifest.json. Install it, copy the xoxb- token, then invite it:

/invite @Foxy
02

Add two values

# .env
SLACK_BOT_TOKEN=xoxb-…
SLACK_TARGET=C0ABC123DEF

The channel ID is at the bottom of View channel details.

03

Run it

docker compose up -d

Or directly:

pip install -r requirements.txt
uvicorn app.main:app --port 8000
04

Confirm

python -m app.cli test-alert
python -m app.cli sweep --dry

Run the sweep twice. The second should report 0 new — that's the memory working.
