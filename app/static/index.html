The idea

YC's directory runs late.

Everyone scraping it finds the same companies on the same day. But most of a batch isn't listed yet — and those founders are already posting.

24
Listed by YC
100s
Actually in the batch
5
Sources watched

So Foxy treats the directory as the answer key, not the source. It reads founder posts first, then asks the directory whether YC has published them yet.

The pipeline

From a post to an alert.

1

Collect

Every eight hours it checks all five sources for anything new.

2

Filter

Drops the obvious noise — recruiters, advice threads, people congratulating a friend.

3

Understand

Pulls out the company name and batch from how the founder actually wrote it.

4

Verify

Looks the company up in the official directory — YC's, or Speedrun's for a Speedrun company.

5

Alert

Posts to Slack, saying which of the three outcomes it found.

Outcome 1
Early

The founder announced, but the directory doesn't list them. This is the alert worth acting on.

Outcome 2
Confirmed

Already published. Still useful, just not exclusive.

Outcome 3
Unverified

No company name could be read. Foxy says so instead of guessing, and files it in a daily digest.

Why that third one matters. If Foxy can't identify a company, it doesn't get to claim the company is missing from YC — it simply doesn't know. Treating “I couldn't check” as “it isn't there” is how a monitor starts crying wolf.

Accuracy

Measured, not claimed.

Tested against 15 real posts collected live and labelled by hand — 8 genuine founder announcements, 7 lookalikes.

False alarms

The lookalikes all contain a textbook announcement phrase and would fool a keyword search: “8 startups I referred got into YC”, “exactly one year ago today, we got into Y Combinator”, “I invested early into a startup that was recently accepted”.

Setup

Five minutes, one token.

You need a Slack workspace and either Docker or Python. Nothing else — no paid APIs.

Create the Slack app

At api.slack.com/apps choose Create New App → From an app manifest, then paste in slack-app-manifest.json.

Install it, copy the xoxb- token, then invite it to your channel:

/invite @Foxy

Add two values

Copy .env.example to .env and fill in:

SLACK_BOT_TOKEN=xoxb-your-token
SLACK_TARGET=C0ABC123DEF

The channel ID sits at the bottom of View channel details in Slack.

Run it

docker compose up -d

Or without Docker:

pip install -r requirements.txt
uvicorn app.main:app --port 8000

That runs Foxy continuously, checking every eight hours.

Check it works

python -m app.cli test-alert   # posts a sample
python -m app.cli sweep --dry  # run once, no posting

Run the sweep twice. The second should say 0 new — that's the memory working.
